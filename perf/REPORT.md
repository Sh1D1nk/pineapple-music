## 4. 卡顿归因

| 条件 | 专辑页热打开 |
| --- | ---: |
| 当前 | 43 ms |
| glassOff | 43 ms |
| bgOff | 46 ms |

- **原生 View Transition 的整屏快照**：关掉转场后专辑详情 20 ms，开着 106–139 ms。这是集显上最大的一笔固定开销，已做成设置项「页面转场动画」（默认保留观感）。
- **隐藏页面的重新栅格化**：保活页面用 `display:none` 时切回要 133–188 ms；换成「绝对定位 + visibility」后 44–65 ms。
- **未虚拟化的网格/列表**：1500+ 卡片一次挂载是冷打开的主要成本；虚拟化后只渲染可见两三行。
- **详情页整屏 blur(28px) 背景**：改成 80px 缩略图放大，省掉一次整屏高斯模糊。
- **玻璃折射**：完整折射相对简化增加约 15 ms/次切页；已限制为小表面（≤6 块），大面板降为磨砂。
- **后台分析/分轨**：见下一节。

## 8. 预算对照

| 预算 | 目标 | 实测 | 结论 |
| --- | --- | --- | --- |
| 热打开 p95 | ≤ 50 ms | 最差目标 176 ms | 未达标（见下表） |
| 冷打开 | ≤ 150 ms | 最差目标 424 ms | 未达标 |
| 滚动 p95 | ≤ 一帧预算 | 8.5 / 8.5 ms | 达标 |
| 点击后 300ms 长任务 | 无 > 50 ms | 0 ms | 见上表 |
| 播放点击到出声 | ≤ 80 ms | 10 ms | — |

未达标项与原因：

- 专辑详情/艺人详情在「页面转场动画」开启时，原生快照固定要 ~80–100 ms（集显整屏捕获）；关掉后 20–30 ms。默认保留动画，预算在关闭转场时达标。
- 专辑页热打开 50–80 ms：剩余成本主要是切页时整窗重新合成的固定成本；滚动 p95 仍在预算内。

## 9. 本轮改动

- 新增 `perf/` 测量核心：点开分段（sync / data / commit / paint / cover）、帧分布、长任务、LoAF 脚本归因、点击到出声。
- HUD（Ctrl+Shift+P）：FPS p50/p95/p99、长任务、最近 20 次点开、主进程事件循环延迟、GPU/刷新率/DPR、玻璃面数与位移、后台任务。
- `npm run bench`：Playwright + 真实窗口，输出 JSON 与对比表；`--legacy` 走上一版路径作基线。
- 页面保活（visibility 隐藏）+ 专辑/艺人虚拟化 + 详情页 O(1) 取专辑 + 80px 氛围底。
- 悬浮玻璃播放底栏（胶囊 + 圆按钮 + 弹簧按压 + 进度直写 CSS 变量），设置「播放控制位置」。
- 液态玻璃：bevel 16 / thickness 150（位移 27.9 px）、只保留小表面折射、大面磨砂；`npm run test:glass` 自动验收。
- 后台治理：进程 BELOW_NORMAL、ffmpeg 子进程降优先级、空闲门控（1.5 s 无输入才跑）、设置「后台处理」。
- 性能模式（自动/开/关）：自动按实测 p95 降级玻璃与歌词模糊，动画参数不变。
- 修复曲库迁移把 3.3 MB 旧库覆盖成空库的问题（有标记也核对体积）。
